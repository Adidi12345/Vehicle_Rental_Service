Name of the project: Vehicle Rental Service
Overview: A simple Java program that simulates a vehicle rental system. You can create and add vehicles, clients and rentals. Put your own prices, and manage multiple rentals.
 Features:
Create vehicles (Vehicle / Car)
Create clients (Client)
Manage rentals (RentalService)
  Calculate total price
  Print rental info
Manage multiple rentals (RentalManager)
  Add, search, filter, sort

Example output:
Client: Alex
Vehicle: Toyota
Days: 3
Total price: 150.0

Client: John
Vehicle: BMW
Days: 3
Total price: 240.0
